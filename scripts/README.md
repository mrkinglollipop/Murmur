# Scripts

| Script | Purpose | When |
|--------|---------|------|
| `install-local.sh` | Release build + Developer ID sign → `/Applications/Murmur.app` | Local maintainer install |
| `make-dmg.sh` | Signed DMG (`NOTARIZE=1` recommended) | Package a distributable |
| `publish-sparkle.sh` | Notarize, Sparkle-sign, publish DMG + appcast to `Murmur-updates` | Ship an in-app update |
| `recover-appcast.sh` | Restore a missing appcast from its newest local backup | Recover a failed appcast replacement |
| `release-lib.sh` | Shared release-script validation and helper functions | Sourced by release scripts and their offline helper tests |
| `test-publish-sparkle-helpers.sh` | Offline oracle for publish helpers | After editing `publish-sparkle.sh` |
| `test-install-local-helpers.sh` | Offline oracle for install and shared release helpers | After editing `install-local.sh`, `make-dmg.sh`, or `release-lib.sh` |
| `oracle-dictation-start.sh` | Inspect the live app's recorded dictation-start diagnostic after a fn hold | Product check after audio-engine changes |
| `test-oracle-dictation-start-helpers.sh` | Offline oracle for dictation-start diagnostic helpers | After editing `oracle-dictation-start.sh` |
| `generate-app-icon.sh` | Regenerate iconset + `AppIcon.icns` from source PNG | After changing icon artwork |
| `test-app-icon-helpers.sh` | Offline oracle for icon geometry / drift | After editing icon assets or generator |

**Release path:** `make-dmg.sh` → `publish-sparkle.sh`.

## Signing (`DEVELOPMENT_TEAM`)

Signed scripts need an Apple Developer team ID. Each script honors a
`DEVELOPMENT_TEAM` environment override; if unset, it reads
`DEVELOPMENT_TEAM` from `Config/Team.xcconfig` (copy from
`Config/Team.xcconfig.example`). If both are missing, the script fails with a
clear error.

Unsigned contributor builds use `CODE_SIGNING_ALLOWED=NO` on `xcodebuild`
(see the README build section).

## Generated Xcode project

`Voice.xcodeproj` is generated by XcodeGen and listed in `.gitignore`. Always
run `xcodegen generate` after clone or `project.yml` changes.
