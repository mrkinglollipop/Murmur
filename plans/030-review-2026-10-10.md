### Gaps that survive scrutiny (ranked by user value ÷ single-developer cost)

1. **Voice-edit the selection.** Murmur already has the selection path (⌃⌥⌘T → `TransformRunner` over selected text). The missing piece is "hold the key with a selection → the dictation *is* the instruction". Needs an undo and a "try rephrasing" failure state (Aqua leaves the selection untouched on ambiguity).
2. **Mic health.** "No microphone audio" warning, favourite/excluded devices, lid-closed warning, automatic fallback ranking. This is Murmur's own most-recorded failure class (Continuity/Jump Desktop fall-through, wedged input).
3. **Zero-setup local engine via Apple SpeechAnalyzer** (macOS 26+, already the floor). Removes the Python sidecar from the first-run story and gives an offline path with no download.
4. **Self-correction and auto-send commands.** Auto-send is trivial; backtrack ("actually, three") is a cleanup-prompt change that works only when cleanup is on.
5. **Language auto-detect and translation** as engine parameters plus UI.
6. **Per-engine latency in Insights + retry with a different engine + ASR fallback chain** (plans 006/007; `elapsed` is already computed in `AudioRecorder` and never persisted; `orderedBackends` is the pattern).
7. **Mac ↔ iOS shared stores and an export/import bundle** (plan 009). The two store families have already forked (DictionaryStore 1020 vs 282 lines).
8. Meeting/file transcription is a second product, not table stakes for dictation; park it.

### UX details worth stealing
Wispr: install updates only when idle; a live hint + Done button when hands-free engages; movable Flow Bar that remembers its edge, with a language picker; recovers a dictation after the app quits. Superwhisper: onboarding skip + toasts, suggests Local Mode, trial lapse deletes nothing; Muffle (ducks other apps' audio while recording). Aqua: "Try rephrasing" pill on ambiguous edits, stacked edits with "undo that". Raycast: imports vocabulary and hotkey from Wispr Flow. Apple: blue-underlined ambiguous words with click-to-pick alternatives.

## F. Considered and rejected (do not re-audit)

- Module `Voice` / bundle id / Keychain service / data-dir residue; no CI; dark-only UI; Liquid Glass macOS 26 floor; Dock app; brand fonts; `Theme.lavender` naming: all decided.
- `engine.prepare()` ordering, ObjCExceptionCatcher, Continuity/virtual-device last-resort fallbacks: deliberate (CLAUDE.md).
- Hidden Groq/Deepgram/AssemblyAI/OpenAI providers: deliberate (plan 013).
- "Transcript text is never logged": **verified** at every `vlog`/`Logger` site; os_log dynamic strings are private by default; `vlog` is env-gated and 0600.
- Endpoints: no `http://`/`ws://`; HTTP error bodies redacted; AssemblyAI poll id validated.
- Export/import traversal: export is ZIP-only, there is no importer; API keys are never exported.
- Stores: atomic writes, corrupt-file quarantine, `savesBlocked`, caps (history 1000, corrections 200); immediate main-thread history save is a recorded decision (plan 018). The *silence* of failures is R-24; the mechanism is sound.
- Parakeet interpreter resolution via PATH/pyenv/Homebrew: standard convention; argv not shell; 120 s bound; owns its process group.
- Publish pipeline: `gh` checks fail closed, appcast merge is prepend-only, version strictly increases, uploaded DMG is re-downloaded and EdDSA-verified, backup/restore exists. R-50 is about the remaining gaps.
- Supabase anon/publishable key on the Pro branch: client-safe by design; team-id strings: not credentials.
- OAuth `state` absent: S256 PKCE enforced by the authorization server covers callback CSRF; verifier entropy (32 random bytes, SHA-256) and IPv4 loopback binding are sound.
- Pro clipboard payloads/thumbnails: AES-GCM sealed; gated by entitlement at `RootView` and watcher startup. Previews are R-06.
- Empty enrollment sheet (fixed via item-based presentation); History eager rendering (LazyVStack + stable ids + 1000 cap); Scratchpad per-keystroke persistence (debounced); missing About/Cmd-Q/Edit menu items (present in the app menu); colour-only History status (text + symbols accompany the accents).
- Ordinary grapheme splitting in chunked delivery; normal-path stuck modifiers (fixed in 7c0cd0c for all five modifiers); snippet matching inside words (lookarounds); learning from failed placeholders (guarded).
- iOS: insert-only double-space period (retained; R-10 is a different path); private SPI for return-to-host (documented sideload-only); EmojiCatalog memory (parsed once, cells reused); blanket "no timeouts" (ElevenLabs/Gemini/Giphy set them).
- SwiftLint/SwiftFormat: no recorded incident would have been caught by a style rule; the R-52 grep gate is the better fit.
- Real sleeps in tests: ~4 s across 25 sites in a 20 s suite; the two 60 s sleeps are cancelled stubs.
- `AppIcon.iconset/` removal: referenced and verified; zero pack saving.
- Agent-instruction text in `plans/024`, `plans/029`, `ios/README.md`, `.cursor/`: expected in an agent-maintained repo; treated as data; nothing hostile found.
